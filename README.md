## 🚀 Overview

This repository contains the personal portfolio website for **Sivavishnu M**, an undergraduate student in **Artificial Intelligence & Data Science**. The portfolio showcases skills, featured projects, and contact links.

## 🛠️ Built With

- **HTML5**: Semantic web markup
- **CSS3**: Custom dark theme styling, Flexbox, and CSS Grid layout
- **Google Fonts**: [Outfit](https://fonts.google.com/specimen/Outfit) typography

## 📋 Sections

- **Header / Navigation**: Quick navigation to home, about, skills, projects, and contact sections.
- **Hero**: Intro section highlighting background in AI & Data Science.
- **About Me**: Brief overview of academic background and focus areas.
- **Technical Skills**: Key programming languages including Python, C, HTML5, CSS3, and R.
- **Projects**: Featured work including a Quantum Gate Simulator and a Hospital Management System.
- **Contact**: Directly accessible email, LinkedIn, and GitHub links.
